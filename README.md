# Aurora Technologies Tools

A comprehensive suite of 34+ business tools for consulting, fintech, AI automation, and marketing.

## Live Site
Visit: [https://abstractfocus.github.io/auroratools/](https://abstractfocus.github.io/auroratools/)

## Tools Include
- **Assessments**: SMB Self-Assessment, Digital Readiness, Data Readiness, Compliance Checker
- **Calculators**: ROI, TCO, Budget Planner, Revenue Model, Pricing Strategy, Automation ROI
- **Consulting**: Proposal Generator, Engagement Scoping, Meeting Prep, Utilization Tracker, Invoice Generator, Engagement Health Monitor
- **CRM & Pipeline**: Client Tracker, Pipeline Analytics, Reminders, Webhook Notifications
- **Strategy**: Scenario Planner, Weighted Scoring Model, Benchmarking, Report Cards, KPI Dashboard
- **AI/Automation**: AI Use Case Evaluator, Data Readiness Assessment, Automation ROI Calculator
- **Marketing/PR**: Content Calendar, PR Pitch Generator, Campaign ROI Tracker, Email Templates
- **Data**: Data Pipeline (export/import hub)
- **Innovation**: Business Idea Generator with personalized profile-based ideation

## Tech Stack
- Vanilla HTML, CSS, JavaScript
- No frameworks or dependencies required
- Data persists in browser localStorage
- Dark mode, responsive design, CSV export, URL sharing

## Getting Started
Just open `index.html` in your browser — no build step required.
